## Hand-in

`main.ts` (Node 22, standard library only) copies `entry.png` from beside
itself to `/output` (1024 × 1024 PNG, 611,862 bytes). Outside the grader,
`MAKEFUN_OUTPUT_DIR` stands in for `/output`:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
